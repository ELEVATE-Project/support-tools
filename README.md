# JSON to CSV Report Generator

This project consists of two Python scripts that process JSON files from the local machine and generate CSV reports. The two reports are:

- **Status Report**
- **Question Report**

## Features

- Read JSON files from the local system
- Parse and process data
- Export clean CSV reports
- Lightweight and easy to use

## Requirements

- Python 3.x
- No external libraries required
